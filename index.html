👋 Welcome to Multivac

To load deployment data you need a GitHub personal access token with access to the Viostream org. It's stored only in your browser's localStorage and never leaves your machine.

  1. Go to GitHub → Settings → Personal access tokens → Generate new token (classic)
  2. Give it a name like Multivac
  3. Set an expiry (90 days is fine)
  4. Tick these two scopes:
repo workflow

Click Generate token, copy it, and paste it below.

Token is saved to localStorage in this browser only. To update it later, click the 🔑 Token button in the toolbar.
