👋 Welcome to Multivac

To load deployment data you need a GitHub personal access token with access to the Viostream org. It's stored only in your browser's localStorage and never leaves your machine.

  1. Go to GitHub → Settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Set Resource owner to Viostream (not your personal account)
  3. Set an expiry (90 days is fine)
  4. Under Repository access, select All repositories or just viostream
  5. Under Permissions → Repository permissions, set:
Actions: Read & Write Contents: Read Deployments: Read & Write Metadata: Read

Click Generate token, copy it, and paste it below. You may need a Viostream org admin to approve it.
Stu or Paul can approve at github.com/organizations/Viostream/settings/personal-access-tokens

Token is saved to localStorage in this browser only. To update it later, click the 🔑 Token button in the toolbar.
